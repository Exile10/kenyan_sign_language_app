# Kenyan Sign Language (KSL) Translator

Open-source Android app that translates Kenyan Sign Language gestures to text in real time using on-device machine learning.

## Status

Active development. Current accuracy: 76% on 26-sign test set. Fully on-device (TensorFlow Lite) — no internet required.

## Tech Stack

- Android (Kotlin)
- TensorFlow Lite (on-device ML inference)
- Camera2 API for real-time gesture capture

This project demonstrates Jarida's edge AI capability — on-device ML inference without cloud dependency. The same architecture powers ClimateShield AI's offline CHW module. See: github.com/jarida-io/climateshield-ai
